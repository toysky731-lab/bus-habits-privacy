# 巴士習慣 Bus Habits — Privacy Policy

The public privacy policy for the iOS app 巴士習慣 (Bus Habits).

Published at <https://toysky731-lab.github.io/bus-habits-privacy/>

The app has no backend. Habits and saved routes stay on the device and in the
user's own iCloud private database. Anonymous usage analytics go to PostHog,
and are structurally incapable of carrying typed text — every event is a case
of one Swift enum whose parameters may only be an integer, a boolean or a
closed set of options.
